## Objective
Load the Global Superstore dataset into Python (Pandas) and perform data cleaning: 
handle missing values, check for duplicates, and convert data types.

## What I did
- Loaded ~51,000 rows of Global Superstore data using Pandas
- Identified missing values in the 'Postal Code' column (mostly non-US orders) and handled them
- Checked for duplicate rows (found: 0 duplicates)
- Converted 'Order Date' and 'Ship Date' from text to proper datetime format
- Exported the cleaned dataset to a new CSV file
